IPL AI Dashboard

Overview

This project is an interactive IPL Dashboard built using Streamlit, Pandas, and Plotly. The dashboard provides insights into IPL matches from 2008 to 2022 through key metrics, visualizations, and interactive filters.

Features

- Dataset Overview
- Data Cleaning
- Key Performance Indicators (KPIs)
- Interactive Filters
- Matches Per Season Analysis
- Top Cities Analysis
- Winning Teams Analysis
- Toss Decision Analysis
- Player of the Match Analysis

Dataset

Dataset: IPL Matches 2008–2022

Technologies Used

- Python
- Pandas
- Streamlit
- Plotly

Instructions to Run

1. Install required libraries:
   pip install streamlit pandas plotly

2. Open terminal in the project folder.

3. Run the application:
   streamlit run app.py

Output

The dashboard displays IPL match statistics, trends, and visual insights using interactive charts and filters.
